# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

The primary use is personal recording and review on Windows, including LINE desktop.

## Product Purpose

Capture and transcribe meeting audio, including Thai-English code switching, and produce detailed notes that help a person revisit decisions, assignments and source evidence.

## Operating Context

Target conversations include Google Meet, Zoom and LINE on Windows. The current evaluation uses simulated audio only.

## Capabilities and Constraints

Meet2Notes is an existing self-hosted web application. Separate local microphone and system-audio sources and mixed-language speech require validation on actual hardware and conversations before any reliability claim. Clearly distinguish generated output, unsupported claims and unverified model performance. Do not start audio devices without an explicit user action.

## Brand Commitments

The user wants a dark, minimal interface that prioritizes reading transcripts. They approved the layout in .impeccable/mocks/concept-3.png with a dark palette adaptation.

## Evidence on Hand

Existing app source, synthetic audio and benchmark artifacts in this repository. No real LINE call or real microphone recording was authorized for this evaluation.

## Product Principles

- Make recording status and input sources explicit.
- Keep transcript evidence reachable from notes.
- Surface uncertainty rather than inventing decisions or owners.
- Make ordinary review and search understandable without model expertise.
