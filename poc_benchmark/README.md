# Thai ASR smoke comparison

Run only on audio you are allowed to process. Public sample: [NECTEC LOTUSDIS](https://huggingface.co/datasets/nectec/LOTUSDIS), CC-BY-SA 4.0. It contains Thai far-field meetings. A few first rows are a smoke test, not a representative benchmark for a LINE call or code-switching. Some models may have trained on this dataset. Do not infer model rankings for other environments.

Requires Python, ffmpeg on PATH, and `openai-whisper` plus PyTorch. `--device cuda` requires a compatible PyTorch/CUDA installation. The chosen models are downloaded by Whisper if missing; check disk, memory and model licenses first. No cloud inference is used.

```powershell
python poc_benchmark/fetch_lotusdis.py --count 5 --out poc_benchmark/lotusdis
python poc_benchmark/benchmark.py --manifest poc_benchmark/lotusdis/manifest.json --models tiny base --device cpu --out poc_benchmark/results.json
```

A custom manifest is a UTF-8 JSON list of objects `{"audio":"relative.wav", "reference":"ถอดเสียงที่คนตรวจแล้ว"}`. Paths resolve relative to the manifest. The result contains transcripts: treat as sensitive, do not publish private data. CER is a character-level metric, not percent correctness, and punctuation/spacing are excluded after NFC and case folding. Compare names, English words, speakers, overlap, omissions, latency and human review separately. The report records errors per model rather than presenting failed runs as scores.

## Two simulated sides, Thai-English

On Windows with the local `Microsoft Pattara` Thai SAPI voice, Python with NumPy,
`ffmpeg`, and network access to Google Translate TTS. Choose an output directory
that does not already exist (the generator never overwrites a previous run):

```powershell
python poc_benchmark/synthetic_dual.py --output poc_benchmark/synthetic
$env:OMP_NUM_THREADS = '4'
$env:MKL_NUM_THREADS = '4'
python poc_benchmark/benchmark.py --manifest poc_benchmark/synthetic/manifest.json --models tiny base --device cpu --out poc_benchmark/synthetic/results.json
python poc_benchmark/benchmark.py --manifest poc_benchmark/synthetic/full-manifest.json --models tiny base --device cpu --out poc_benchmark/synthetic/full-results.json
python -m unittest discover -s poc_benchmark -p test_synthetic_dual.py
```

The first fixture voice is generated locally by SAPI; the second is generated by
Google Translate TTS using **fictional test text** over the network. No microphone
is opened. The script feeds two synthesized source tracks into Meet2Notes'
`AudioMixer`; it records no OS devices. It checks each turn's signal against its
source and produces separate tracks, a full mix, and per-turn excerpts. Thus this
checks the software mixer, not a Windows mic, system loopback, real LINE call,
diarization or overlapping voices. The English and deadline checks are literal
string matches; transliterations and equivalent number spellings will be marked
as misses even when understandable. TTS generation can change between runs;
the benchmark records SHA-256 hashes for the actual evaluated audio. The reference
is the text provided to TTS, not a human-audited phonetic transcript.
